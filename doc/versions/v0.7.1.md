# v0.7.1 — PR #10 Code Review 反馈修复

> Release date: 2026-06-14

## Bug 修复

### API 响应验证 — 防止无限循环
- **commits** `408b8dc`
- **`opencode_go_provider.rs`**：`parse_chat_response` 改为返回 `Result<ChatMessage, AiError>`，增加对 `choices` 数组存在性/非空性和 `message` 子字段的防御性检查。`chat` 方法增加 `error` 顶级字段检查，API 返回错误时立即返回 `AiError::ApiError`，防止上游 agent 循环进入无限重试。
- 提取 `extract_message` 和 `parse_tool_calls` 辅助函数，消除 `tool_calls` 解析中的潜在 panic 路径（使用 `.get()` 链式调用替代直接索引）。
- 新增 6 个单元测试覆盖正常含内容、含 tool_calls、choices 缺失、choices 为空、message 缺失、error 与合法响应共存等场景。

### GrepTool 参数注入漏洞修复
- **commit** `a8ffe9e`
- **`grep.rs`**：在 `run_grep` 的 pattern 和 path 参数前插入 `--` 分隔符（POSIX 选项结束标记），防止以 `-` 开头的 pattern（如 `--help`、`-r`）被 grep 解释为命令行选项。
- 新增 `validate_extension` 函数对 `extension` 参数进行白名单校验（仅允许字母、数字、下划线、连字符和点号），实现纵深防御。
- 新增 4 个单元测试覆盖 `--help` pattern、`-r` pattern、非法 extension、合法 extension 场景。

### Sub-Agent Runner panic 保护
- **commit** `19110e2`
- **`sub_agent_runner.rs`**：使用 `std::panic::catch_unwind` + `AssertUnwindSafe` 包裹 `tool.execute()` 调用，将 panic 转换为格式化的错误消息 `"Panic in tool '{name}': {msg}"`，防止单个工具 panic 导致整个 sub-agent 进程崩溃。
- 改进 `save_sub_agent_session` 的错误处理，从 `let _ =` 静默忽略改为输出 warning 日志。
- 新增 4 个单元测试覆盖 panic 捕获、正常执行、错误返回、未知工具场景。

### 移除 eprintln! 避免 TUI 渲染干扰
- **commit** `f05832d`
- **`persistence.rs` / `sub_agent_runner.rs`**：将 `eprintln!` 调用替换为 `log::warn!` 宏。`log` crate 默认无 logger 时静默丢弃所有日志，彻底避免 TUI 环境下 stderr 输出破坏终端渲染。
- 根 `Cargo.toml` 和 `oy-agent/Cargo.toml` 新增 `log = "0.4"` workspace 依赖。

### BashTool 超时机制 — 防止线程/进程泄漏
- **commit** `d44dd4d`
- **`bash.rs`**：实现基于 `std::thread::spawn` + `mpsc::channel` + `recv_timeout` 的超时机制。从 args 提取 `timeout` 参数（默认 150 秒），超时时通过 PID 使用系统 `kill -9`（Unix）/ `taskkill /F`（Windows）强制终止子进程，并 `join` 线程确保无僵尸进程残留。
- 新增 3 个单元测试覆盖正常执行、超时触发、默认 timeout 场景。

### EditTool 空文本验证
- **commit** `c54e06b`
- **`edit.rs`**：在 `execute` 方法中增加 `old_text` 空字符串校验，拒绝空 `old_text`（防止 `content.find("")` 导致的意外全局替换行为）。空 `new_text` 仍为合法删除操作，不做限制。
- 新增 2 个单元测试覆盖空 `old_text`（期望 Err）和空 `new_text`（期望成功删除）。

### 简化 replace_messages 冗余循环逻辑
- **commit** `0866fd1`
- **`agent.rs`**：将 `replace_messages_preserve_system_prompt` 中「先取首元素判断 role，再遍历剩余元素」的冗余循环模式，简化为 `if let Some(msg) = iter.next() && msg.role != Role::System { messages.push_back(msg); } messages.extend(iter);`，逻辑等价且更清晰。

### 移除辅助函数中的 std::process::exit
- **commit** `aa26a1a`
- **`oy-code-cli/src/lib.rs`**：`build_provider_config` 返回 `Result<AiConfig, String>` 替代直接 `exit(1)`；`run_update` 和 `run_session_path` 中的 `exit(1)` 改为 `return Err(...)`，利用函数已有的 `Result<(), anyhow::Error>` 返回类型自然传播错误。
- **`oy-tui/src/load_config.rs`**：`build_provider_config` 返回 `Result<AiConfig, String>`，将 `exit(1)` 替换为 `ok_or_else` 返回 `Err`。
- **`oy-tui/src/app.rs`**：适配 8 处调用点，使用 `.expect("config_is_complete guarantees api_key is set")`（所有调用点均受 `config_is_complete` 守卫保护）。
- 移除不再需要的 `use std::process;` 导入。

## 功能特性

### Input 历史 prompt 浏览 — ↑/↓ 切换
- **commit** `1c3fcf6`
- **`app.rs`**：新增用户历史 prompt 浏览功能。当 input 为空时，按 `↑` 键自动从对话历史中提取所有 user 角色的消息内容，按从新到旧顺序填入 input 缓冲区。
- **连续切换**：持续按 `↑` 切换到更旧的历史 prompt；按 `↓` 切换到更新的 prompt。
- **归位清空**：在最新历史 prompt 处按 `↓` 退出历史模式并清空 input。
- **自动退出**：输入任意字符或按 Enter 提交时自动退出历史浏览模式，恢复正常的编辑行为。
